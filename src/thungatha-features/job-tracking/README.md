# Job Tracking

Reserved feature boundary for actual job application records, application status, history, follow-ups, next actions, and submitted-material references.

Planned areas:
- `ui/` — application lists, detail views, status updates, and follow-up workflows.
- `server/` — application-record validation, ownership checks, persistence, and lifecycle operations.

This is structural scaffolding only. Do not treat a saved or opened job listing as an application, and do not claim an application was submitted unless the user confirms it.
